# 🌌 Nebula Edge
> **The Sarcastic, Native-Engine AI for Creators & Gamers.**

Nebula Edge is a high-octane AI companion built to handle complex coding (Roblox Luau specialist), physics-based animation, and gaming strategy.

### 🧠 Features
- **Engine-Native:** No APIs. Pure, raw compute.
- **Architect Mode:** Expert-level coding and Roblox Studio optimization.
- **Game-Sense:** Pro-tier gaming advice with a sarcastic bite.
- **Visuals:** Native 4K image and video generation.

### 🛠️ Setup
1. `npm install`
2. `npm run dev`
3. Don't ask it stupid questions unless you want to be roasted.
